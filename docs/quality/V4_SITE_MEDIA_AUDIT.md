# V4.0 全站媒體與現況照片稽核

## Existing catalog

The existing media catalog contains the following relevant groups:

- Aerial references: 1944 display assets and 1944/1945/1958 low-resolution POC mosaics.
- Historical/source map: the user-provided battle route map with schematic and internal-test rights note.
- Archive photographs: four Wang Wan-nien records from the National Cultural Memory Bank, CC BY 3.0 TW+.
- Person context: two Hu Lien images from the National Cultural Memory Bank, CC BY-NC 3.0 TW+.
- Then-and-now site photographs: museum, Beishan cliff, broadcasting wall, Beishan old house, Guningtou beach, Li Guangqian Shrine, Peace Memorial Park, Lincuo memorial, and Guningtou arch. Each catalog entry retains author, date, source URL, and licence.
- Xiamen aerial candidates: eight research-only images under `public/media/guningtou/xiamen-aerial/`; they are not used as verified historical evidence.

## Safety checks

- The V4 audit found no missing public asset for the static catalog paths.
- Research-only aerial candidates remain marked `research` and are not silently promoted.
- No new remote image was downloaded or added from an unverified search result during V4.
- A photo of one location must not be reused as another site’s evidence. Missing site photos remain a research/licensing task rather than a blank card disguised as a fact.

## Remaining media work

The important military facilities and camp records still need site-specific, legally cleared photographs where available. Priority includes Andong 1/2/3, Huxia, the broadcasting wall, Beishan command-related remains, bunkers, and the landing coast. The review queue records these as acquisition tasks, not completed assets.
