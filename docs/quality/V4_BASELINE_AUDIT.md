## Baseline findings

- Every inspected canonical ID set is unique.
- Existing source references resolve to `data/sources.json`; no second editable source registry was created.
- All 25 POIs are `partially_verified`; none is safe to display as a verified coordinate.
- All 36 person records have English names, but the canonical data has no complete localized biography fields.
- `portrait_assets` is empty in the canonical person data. Only the existing media catalog links two legally attributed contextual images to `PER-0003`; the other people need a neutral placeholder or a separately cleared portrait.
- The POI records from `POI-0004` through `POI-0025` contained the same unrelated Housha long narrative. V4 replaces that copied narrative with a source-review note; it does not invent a replacement historical account.
- Existing map and trace assets remain schematic/research material unless their own evidence state says otherwise.
