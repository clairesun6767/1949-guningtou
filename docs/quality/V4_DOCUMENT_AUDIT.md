# V4.0 文獻、來源與文件稽核

## Source registry

`data/sources.json` remains the only authoritative editable source catalog. The current repository contains 55 records. V4 did not create `sources-v2.json`, `new-sources.json`, or another competing registry.

The V4 work references official government and national-park pages for site discovery, but a web page being reachable does not automatically support a precise 1949 coordinate, unit claim, or route. Page numbers, archive IDs, excerpts, and human source decisions remain required for Evidence Gate closure.

## Document decision

The current evidence package remains auditable but not sufficient to close all P0 gaps. V4 therefore does not enable a new historical event, unit, route, or exact location. This is an evidence-safe blocked result, not a reason to fabricate missing documentation.
